# old-tools — the three scripts, run separately

These are the individual stages. Each one does a single job and hands off to the
next through files on disk, so you can run just the part you need.

If you want the whole thing in one command, use [`../new-tool/`](../new-tool/)
instead.

For *why* the code is shaped the way it is — the portal's traps, the bugs found
and how they were caught — see **[TECHNICAL.md](TECHNICAL.md)**.
[STATUS.md](STATUS.md) is the project handover note.

---

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Also needs:

- **Google Chrome** — the downloader drives your system Chrome rather than
  downloading its own browser (`channel="chrome"`)
- **`pdfimages`** (poppler-utils) — used to pull the QR image out of each PDF
  - Fedora: `sudo dnf install poppler-utils`
  - Debian/Ubuntu: `sudo apt install poppler-utils`

## The three scripts

### 1. `balady_certs.py` — download the certificates

Fills the portal's advanced-search form, submits it, and downloads certificate
PDFs from the results grid, keeping the portal's original filenames
(`<certNo>_<uid>_شهادة التصنيف.pdf`).

```bash
.venv/bin/python balady_certs.py                  # 5 certificates (default)
.venv/bin/python balady_certs.py --all            # ~100, pages 1-10, ~25 min
.venv/bin/python balady_certs.py --city جدة        # a different city
.venv/bin/python balady_certs.py --list-options   # show every dropdown's values
.venv/bin/python balady_certs.py --headed         # watch the browser work
```

Output goes to `pdf_files/` by default, alongside a `manifest.csv` logging what
was fetched.

| Flag | Default | Meaning |
|---|---|---|
| `--city` | `الرياض` | المدينة — 220 available, see `--list-options` |
| `--type` | `منشآت مصنفة` | نوع التصنيف / التأهيل |
| `--field` | `مجال التشييد والبناء` | المجال |
| `--grade` | `درجة اعتماد` | درجة التصنيف / التأهيل |
| `--from` / `--to` | `30/09/2026` / — | certificate expiry range, `dd/mm/yyyy` |
| `--limit` | `5` | how many; `0` = as many as reachable (~100) |
| `--all` | off | shorthand for `--limit 0` |
| `--outdir` | `./pdf_files` | where to save |
| `--delay` | `2.0` | seconds between downloads |
| `--headed` | off | show the browser |

Resumable — it skips any certificate already present in the output folder, so
Ctrl-C costs nothing and rerunning continues where it stopped.

### 2. `qr_details.py` — read the QR codes

Every certificate has a small QR in the bottom-left linking to a Balady page
that publishes the establishment's contact details. This extracts the QR
straight out of the PDF, decodes it, fetches the page and parses it.

```bash
.venv/bin/python qr_details.py                 # process ./pdf_files
.venv/bin/python qr_details.py --limit 5       # trial run
.venv/bin/python qr_details.py --show          # print each record
.venv/bin/python qr_details.py --pdf-dir other/folder
```

Writes `qr_details.csv` next to the PDFs: `uid`, `facility_name`, `owner_name`,
`phone`, `email`, `city`, `region`, `activity`, plus provenance columns.

No browser needed — the target page embeds its data as JSON, so this is one
plain HTTP request per certificate (~6 s each). Resumable the same way.

### 3. `make_excel.py` — CSV to Excel

```bash
.venv/bin/python make_excel.py                         # qr_details.csv -> .xlsx
.venv/bin/python make_excel.py --csv manifest.csv
.venv/bin/python make_excel.py --out ~/Desktop/report.xlsx
```

Produces a workbook with bilingual headers, a frozen filterable header row, a
right-to-left sheet for Arabic, and sized columns.

**Why this exists instead of just renaming the CSV:** Excel silently corrupts
this data on open. Saudi mobile numbers lose their leading zero
(`0512345678` → `512345678`) and 10-digit company numbers flip to scientific
notation (`7042013313` → `7.04201E+09`). The script writes those columns as real
text cells, which is the only reliable fix.

## Running them as a chain

```bash
.venv/bin/python balady_certs.py --all ; \
.venv/bin/python qr_details.py ; \
.venv/bin/python make_excel.py
```

Use `;` rather than `&&`. The first two scripts exit `1` on *partial* failure —
if 3 certificates out of 100 fail, that is still a useful result, but `&&` would
abandon the pipeline and you would never get the spreadsheet.

[`../new-tool/run.py`](../new-tool/run.py) does this properly, with a city
prompt, a dated output folder and a summary.

## Limits

- **~100 certificates per search.** The portal resets its grid to page 1 after
  every download and its pager exposes only 10 pages. See TECHNICAL.md §4.12.
- **Arabic will not extract from the PDFs** with `pdftotext` — they are
  generated by PD4ML without a ToUnicode map. Use the portal's own تصدير
  (export) button if you need the results table as text.
- **Speed is set by the server**, roughly 15 s per certificate. Parallelising
  would mean hammering a public service; deliberately not done.
